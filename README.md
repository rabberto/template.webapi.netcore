# template.webapi.netcore
This repository contains a template for a Web API application developed using the Domain-Driven Design (DDD) approach, featuring a clear and organized layered structure. The template is configured to support multiple databases, selected based on the secret key received in the request header. In addition, the project includes an efficient mapping of the settings contained in the appsettings.json files to specific classes, facilitating configuration management. The application uses the Entity Framework as an Object-Relational Mapper (ORM), ensuring efficient and intuitive data persistence and querying. Finally, the repository is already implemented and instrumented to use ILogger, integrated with ElasticSearch, providing a robust solution for logging and monitoring logs.
